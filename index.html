Project 01 — Mechatronics

Real-time EMG Gesture Recognition

A triple-channel electromyography (EMG) sensor system built from scratch to capture and classify muscle signals in real time. Custom analog front-end circuits amplify and filter raw bio-signals before a microcontroller runs signal-processing algorithms to distinguish gesture classes. The system was initially conceived to record arm movements for classical dance choreography, then extended toward a broader health and injury-prevention monitoring concept.

Interface

Project 02 — Mechatronics

Persistence of Vision Display

An Arduino Nano orchestrates a spinning LED strip and DC motor to produce the persistence-of-vision illusion — where a rapidly sweeping row of LEDs appears as a full 2D image to the human eye. The core challenge is precise timing synchronisation between the motor's rotational speed and the LED update rate. The project demonstrates real-time interrupt handling, PWM motor control, and LED driver coding.

Controller
Arduino Nano
Actuation
DC motor + LED strip
Technique
POV timing sync
Domain
Embedded · Mechanical
Project 03 — Mechanical

Peristaltic Pump Prototype

Starting from an existing peristaltic pump design, this project reverse-engineered the mechanism to understand its principles and then redesigned key components for ease of manufacture and broader application. Improvements focused on simplifying the rotor geometry, reducing part count, and specifying tolerances that support low-cost fabrication methods without sacrificing performance.

Project 04 — Mechatronics

Valve Automation System

Designed an electromechanical solution to automate the operation of an existing manual valve. The work covered actuator selection, mechanical bracket and coupling design to mount the actuator onto the valve body, and control interfacing to enable remote or automated operation. Special attention was paid to maintaining back-compatibility with manual override.
